# 6R 第二輪：參照／待測聯合分割與候選整理

沿用6R分支；5R正式站台、模型、範例、門檻及判定不改。本輪工作接續[第一輪](CHECKPOINT_6R_BOUNDARIES_20261120.md)，不需要再次取得使用者授權才往下做。

## 本輪實作

`joint_boundary6r.py`先用候選之外的周邊做兩種範圍對應，沿用相關性0.75、位移差2、搜尋12及原明暗條件。可靠度不足就保留未知，不用附近相似圓形當正常答案。

候選核心仍使用原0.13差異門檻，未降低DINO門檻。對可靠對應者，同時以待測灰階、校正後參照灰階及正差分作聯合特徵，實測分水嶺與圖割兩種方法。正差異在核心內的像素是前景；沒有新增暗差異的位置及其他差異區是背景／競爭標記。未知部分由分割處理，不能把整條連到板件的差異都硬指定為物件。

兩種周邊對應×12／20／32三種分割範圍共六組。需要保住核心、不碰搜尋邊界，且遮罩IoU至少0.8，才記可見差異穩定假設。此處仍不是物件完整性驗收。碎片合併要求同組任何兩遮罩都達0.8，不使用距離或傳遞合併；全部來源ID保留。

`candidate_organizer6r.py`將可見差異與外圍物件範圍分開：共享暗結構只作證據，不單獨阻止尋找外圍，因真實物件也可能投影在板件上。用第一輪固定灰階切面找跨切面穩定外圍，選最外層有支持的輪廓，不用DINO分數挑框；找到同一輪廓的碎片才合成一組。找不到輪廓就保留未知，不用小差異框冒充完整物件。早期曾將共享暗邊界作資格限制，發現過度保守後已移除；部分中途結果另存v1，不能混入最終統計。

## 雙圖實測的範圍

在新的隔離研究站台載入原權重與原圖庫；現站主庫52＋90、完整輪廓副庫47＋65均未增刪。實際診斷使用原47＋65四範圍雙圖函式：待測四範圍平均支持螺絲，且每個參照範圍均不支持，才記支持保留。不是單圖，不改門檻。

先對全部符合「可見差異穩定且無共享暗邊界」的組做核心裁圖對照，再對全部有穩定外圍輪廓的組做外圍裁圖實測。其餘逐一列出未推論原因，不使用抽樣冒充全批。這是新裁圖的實際DINO推論，但**不是重跑正式5R完整入口，也不是新的正式警報**。

核心對照使用CPU；外圍實驗使用本機既有GPU環境加速，正式站台仍是CPU。先用三組相同裁圖比對，保留／排除皆一致，最大分數差約4.47×10⁻⁷；這不是全批CPU／GPU等價驗收。已完成的外圍CPU結果另保留並與最終GPU結果逐組比較。GPU外圍全批獨立完成，不把中途CPU結果混入全批GPU統計；沒有用數值容差更改門檻。
