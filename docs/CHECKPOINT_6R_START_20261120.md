## 6R 已同意的方向

1. 對位與明暗校正維持必要責任，讓影像可比較。
2. 差分負責保留有意義的變化位置與強度，不提前用附近正常結構抹掉可能物件。
3. 候選整理負責：有輪廓支持地尋找完整範圍；合併同物件碎片；核對原有結構位移／明暗。不能只因鄰近就合併，不能只因附近有相似圓形就排除，對應不足不能當正常。
4. DINO接收整理後的物件與參照對照，減少重複、不完整的輸入。不得改掉既有雙圖規則或任意增刪範例。
5. 盤點位置容忍、去雜點、相似結構排除與各補提流程，明列哪些保留、哪些移交、哪些由新流程取代。先驗證再刪除，不是直接把舊防誤報全部拿掉。
