① 47 張螺絲＋65 張正常範例。
② DINO 同時判斷參照小圖與待測小圖。
採用的範例、取圖方式與判斷規則，均對應完整報告的「新範例＋雙圖」版本。

更正前次交付

前次可攜版只啟用了新範例，沒有啟用雙圖判斷，與使用者要求及報告不一致。請改用檔名包含 DINO-Paired-20261103-r2 的版本。前一包保留供追溯，不應當作雙圖版本使用。

現在的流程

  1. 差分找出可疑位置，保留原本的找框方式。
  2. 在同一位置分別取出待測小圖、參照小圖。
  3. 每張小圖都從 47 張螺絲裡找最像的 3 張、從 65 張正常範例裡找最像的 3 張，分別比較。
  4. 待測圖像螺絲、參照圖不像螺絲：保留。兩張都像螺絲，或待測圖不像螺絲：排除。

若參照小圖缺失或模型失敗，保留候選並顯示錯誤，不會默默改用單圖判斷。upper-green 補完整框的方法仍未套用。

雙圖規則只能比較各自像不像螺絲，還不能確定兩張圖中是同一顆。此限制不會再被用來自行停用使用者已要求開啟的功能。

使用方式

完整解壓縮後雙擊 XRayReview.exe，不用另裝 Python。工程頁面應顯示 「DINO 雙圖：47 張螺絲＋65 張正常」及「參照圖＋待測圖」。DINO 範例管理已整合其中，新增範例存成新版後仍沿用雙圖方式；舊版 DINO 與 CLIP 保留供切換。

本包含四機種正常參照圖，差分門檻 0.13，自動取圖預設關閉，請先選擇此電腦的來源資料夾。資料與設定留在包內，搬移請複製整個資料夾。

完整報告資料與圖片沿用原本「新範例＋雙圖」報告；本次修正的是執行程式，沒有改報告答案來配合程式。
