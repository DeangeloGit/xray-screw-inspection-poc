# 5r 影像逐步追蹤

從已還原並核對資料的 5r 局部複核服務開啟「工程設定 → 影像逐步追蹤」。選擇正常參照圖和待測圖後送出。每次使用獨立工作目錄，沿用現有機種的候選門檻與當前模型。輸入照片與取證資料留在該站台工作區的 `engineering-traces`。

報告可直接開啟或下載為單檔 HTML。27 步包含對齊前後、實際遮罩、亮度校正、差異圖、二值圖、連通區和疊圖。逐框區可展開原圖裁切、模型影像、判定分數及複核欄位。未產出中間圖的步驟依結果欄位追查。工程時間包含取證 I/O。圖旁數字以實際可量的階段為單位，ONNX 次數和耗時另計。

側面補救採用待測先判。待測有一項既有條件不成立時，略過參照推論。KPH33 NG-000004 的驗證中從 258 次降到 250 次，203 個候選的保留／排除及分類證據一致。外露候選維持既有條件。
