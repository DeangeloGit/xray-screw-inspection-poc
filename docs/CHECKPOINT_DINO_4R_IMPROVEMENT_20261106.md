## 本輪固定實驗規則

`experiments/dino/improvement_policy.py` 不讀取答案、照片名稱或答案座標。

1. 在前段以窄容差差分合併鄰近碎片，尺寸、面積、形狀與正負差分受限。
2. 使用外圍 4、8 像素兩種取圖，參照與待測都由同一固定範例庫評分；整體／局部／新增黑影特徵平均。兩種取圖皆須待測至少 0.04、參照小於 0，並具有足夠物件範圍，才能新增保留。
3. 原 r3 保留直接沿用。只對上輪補抓新增的警報做板件輪廓延伸與線材位移檢查。
4. 答案僅在實驗後評估。比較較寬鬆條件會增加框外警報，因此不採用；0.03 與 0.04 的保守結果相同，固定使用 0.04。
