# 現場複判與工程設定（2026-11-02）

## 現場複判 `/`

1. 查看上方機型、取圖來源、參考圖與 AI 狀態。按「切換機型／來源」可同時儲存機型與來源，避免只切換其中一項。來源空白且停用自動取圖時使用本機測試資料。
2. 從左側本批照片選一張；中央看原圖，右側逐位置選「是螺絲／不是螺絲／不確定」。沒有候選時也要人工看全圖。
3. 全部位置判定後，照片結果自動依人工判定彙整，無需再次確認：有任何不確定就列「需再確認」；否則有螺絲就列「確認有螺絲」，全為非螺絲則完成為「人工未見螺絲」。更正任一位置會立即重新彙整。沒有候選時仍需一次人工照片判定；框外發現螺絲或整張有疑問時，可使用選用的補充判定。
4. 底部顯示本批人工複判進度。未完成、需再確認或無法分析的照片不阻擋匯出，會在表單列為「待處理異常」並保留原因；預設涵蓋目前清單全部照片。
5. 按「匯出本批螺絲表單」先預覽，再按「匯出 CSV」。表單包含「螺絲結果」及「待處理異常」，SN 留白。已完成且人工未見螺絲的照片不列入；待處理照片的人工判定為「未判定」，不視為正常或有螺絲。預覽不產生表單檔案；匯出會檢查預覽版本，判定改變時要求重新預覽。
6. 需要指定部分照片時，展開「批次與匯出範圍」，啟用「只匯出勾選照片」。全部檢查也放在此處；分析完成不等於人工複判完成。

來源或機型由其他分頁變更時，清單會在下一次更新時切換，清除目前照片及匯出選取。舊照片及人工紀錄仍保留。新照片須經掃描及寫入穩定等待才會顯示；取圖離線時可繼續複判已取得的本機快照。清單是目前來源的持續取圖範圍；預覽表單會固定該次選取的照片，新進照片不會悄悄加入已開啟的預覽。

## 工程設定 `/engineer`

- **機型與參考圖**：新增機型、選取正常參考圖並預覽後儲存；可查看及更換已存參考圖。原 V1 參考圖保留，需更換時新增機型。缺少參考圖的機型無法在現場選用。
- **取圖資料夾**：瀏覽本機／已掛載分享，或輸入 Windows UNC 路徑。測試連線確認資料夾可讀，按「儲存並切換來源」才生效。穩定等待秒數在進階設定；關閉自動取圖不會清除快照。
- **AI 模型（選用）**：選取 ONNX、CPU 或 NVIDIA GPU，檢查並套用。失敗保留舊模型；尚無真模型時可維持 AI 關閉，仍使用差分與人工複判。
- **機型調校**：由每個機型旁的「調校」進入，單張異常圖試算後再套用至此機型，詳見下方說明。

舊網址 `/settings` 仍可使用，會直接顯示工程設定的取圖分頁。這是作業介面分工，沒有新增帳號／權限限制。

此改版不改動差分演算法或自動放行規則。新增 API：`POST /api/inspection/context`（機型與來源原子儲存）、`POST /api/reports/screws/preview`（經複判檢查的唯讀預覽）。共享樣式 `static/app.css`；主要模板以 partial 分拆，Windows 組裝會一起帶入。

驗證：`verify_ui_workflow.py`、`verify_source_scope.py`、`verify_machines.py`、`verify_settings.py`、`verify_ipc.py`。瀏覽器另實測參考圖上傳、機型切換、逐位置與整張複判、範圍勾選、預覽／下載 CSV、資料夾選擇及窄螢幕無水平溢出。Windows 原生執行仍須實機驗收。

歷史資料：已有明確整張人工判定者保留原判定；只有完整逐位置紀錄者可直接彙整，不要求補按確認。歷史未保存實際複判時間時，表單時間留白，避免用分析時間代替。

分析失敗以影像內容、機型與參考圖版本保存原因；成功重試會清除失敗狀態。CSV 新增「資料類型」「處理狀態」「未完成原因」，保留檔名與來源完整路徑。即使整批全為待處理，也可匯出異常清單；進度仍顯示實際完成數，不因匯出而完成照片。


## 各機型獨立調校

工程設定 → 機型與參考圖 → 該機型旁的「調校」。上傳一張同機型異常照片、調整敏感度，再按「試算並查看結果」。頁面並排顯示此機型正常參考、對齊後異常圖及同方向、同座標的候選標記。下方詳細檢視仍保留原圖方向與原始像素座標。

調校頁只移除「選擇照片」下拉選單，保留上傳照片、候選統計、原圖切換與候選框、候選局部放大與正常參考、差分、九區對齊、第一版追溯、JSON 下載，以及資料夾總覽與原始版本比較。候選的人工註記儲存在該次調校紀錄，不列入正式報表。

試算不變更現場設定，也不把照片加入正式清單。確認結果後按「套用至［機型名稱］」，只儲存該機型門檻。調整滑桿或更換照片後必須重新試算才能套用；參考圖或機型門檻被其他頁面更新時也須重新試算。

設定保存於工作區 `state/ui_settings.json` 的 `machine_thresholds`。切換機型時，現場複判、新照片、自動取圖及全部檢查會採用對應門檻，重啟後保留。未調校機型沿用原有門檻（原共用設定或預設 0.13）。調校其他機型不會切換目前作業機型或來源。

門檻範圍為 0.03–0.40，越低通常越敏感。不同門檻的既有結果與人工紀錄仍保留，但不列為新門檻的完成結果；重新檢查後須依新候選複判。試算資料獨立存於 `state/tuning-previews`，不納入報表。


## 差分 V3 更新

檢測範圍改為正常機體外輪廓內部，包含原先被排除的亮區；對齊仍依原結構區量測。局部亮度增益／偏移補償後，再用小範圍位置容差和輪廓相關性抑制既有結構差異，不再將正常邊緣附近整片清空。過大相連區先嘗試分離，避免把連到結構的螺絲一起丟棄。

這仍是差分候選，並非訓練完成的螺絲辨識模型。新的檢測範圍可能增加候選；細小、重疊、與正常結構相似的異物仍有漏檢風險。舊版結果、照片及人工判定保留在原處，但目前清單只採用最新偵測版本，請重新試算或執行全部檢查，勿把既有完成狀態當作新版驗證完成。


V4 範圍修正：使用主機體連通區的凸包外框，包含與外部相通的側邊凹槽；仍排除與主機體分離的治具與背景物件。其餘 V3 差分及亮度補償規則不變。舊試算需重做，避免用舊範圍的候選套用設定。外框涵蓋更多側邊區域，可能增加候選，仍需人工複判。


V5 小物件補查：主流程維持 3 像素位移容差，另以 1 像素容差檢查靠近既有深色結構的小型差異。補查須同時通過面積、尺寸、緊密度、差分強度、明暗殘差比例與輪廓新穎性限制，並排除和既有候選重疊的重複框。補查候選仍需人工確認；正常鄰近結構支持高者保留為黃色候選。已用新增綠框案例在門檻 0.20 驗證，不能推論所有小螺絲均可檢出。
