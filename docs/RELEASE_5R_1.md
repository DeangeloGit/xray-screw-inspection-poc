# X-RAY 5r.1 效能小版

5r.1 合併 5r 局部複核流程的效能修改。沿用既有模型與範例庫、雙圖判定規則、門檻及裁切尺寸。

- 可見部位的待測分數低於既有門檻時，略過該次參照推論。
- 補提候選先做既有幾何檢查。雙尺寸與四範圍複核遇到必要條件已不成立時，略過無法改變判定的推論。正常接點複核先確認既有長寬比和待測條件，再決定是否需要推論參照圖。
- 重用影像對齊中間結果、亮度校正、雙圖轉換、相同候選的結構檢查與輪廓。報告標示部分略過的分數，結果資料保存略過的尺寸與原因。

## Mac 實測

同一台 Mac、相同 KPH33 OK／NG 各一張，從提交批次到報告校驗結束。表中數值取自各輪單次量測，輪次在不同時段執行。

| 階段 | OK（秒） | NG（秒） |
|---|---:|---:|
| 原版 5r | 24.11 | 39.07 |
| 可見部位先判待測 | 18.19 | 24.78 |
| 加入補提候選幾何先判 | 16.96 | 22.72 |
| 合併重用與正常接點複核優化 | 17.17 | 21.89 |
| 5r.1，加入雙尺寸與四範圍提早結束 | 14.44 | 18.96 |

相對原版，OK 耗時下降 40.1%，NG 下降 51.5%，兩張合計下降 47.1%。最後一輪相對上一輪少做 39／29 次 ONNX 推論，兩張合計下降 14.5%。這兩張仍超過單張 10 秒。

最後一輪逐框核對 313 個候選，座標及保留／排除一致。27 個候選的中間紀錄因省略推論而有差異，已執行的分數一致。兩張都沒有留下警報，NG 個案仍無警報。此驗證範圍為這兩張 Mac 實圖，Windows 實機與全圖資回歸待驗證。
