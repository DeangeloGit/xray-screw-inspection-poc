## 原因與採用規則

現版 `connector_policy.py` 為 `4r-normal-connector-full-shape-four-view-v3-20261106`：

1. 只對原保留的整體物件執行，已排除及B局部沿用原結果。
2. 兩圖保留完整比例，背景2、4、8、12像素，各重新推論；四個待測範圍在原47＋65完整比例範例庫中都必須較接近正常。
3. 另用使用者確認的128 #22作單一正常接點範例，保留旋轉／翻轉8個視角。整體、局部兩特徵的四範圍平均，都必須比每個範圍最相似的螺絲範例更支持該正常接點。
4. 物件長寬比須在正常範例長寬比的0.5～2倍之內，避免把接點紋理套到細長線材旁螺絲。

正常範例庫獨立保存，原47＋65庫不增刪。#40沒有加進正常庫，但已在開發時看過，不能稱盲測。模型執行規則不使用檔名、候選ID、答案座標或人工標籤；#22來源僅用於製作獨立正常範例庫。
