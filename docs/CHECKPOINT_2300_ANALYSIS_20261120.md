3. 4r 補救要求 4／8 像素兩範圍的整體、local、focused 三分數平均都達 +0.04；實際為 +0.064232／+0.005146。8px 的 focused 仍為 +0.103646，但被其他兩項壓低。
4. 舊完整輪廓搜尋的 5×5 開運算只留下 13×8 片段、覆蓋率 43.7%，未達 50% 條件。既有 5r 局部複核只處理已保留警報，因此不會救回這個已排除框。

保持 12px 畫布及核心尺度，人工把框外背景改成白底的診斷對照，待測分數變成 +0.157185。這支持背景內容影響；**人工改背景不是採用的偵測方法**。

## 建議整合的補救

僅處理原流程完成後，新外殼通道內被排除、最大邊不超過 32 像素的小候選。先決定影像幾何，再比較 DINO，不能挑最高分框。

- 在 8／12／20px 三種周圍範圍分別用 Otsu 分割，取得與候選重疊的物件；不先做破壞小螺絲形狀的 5×5 開運算。
- 三框 IoU 至少 0.8，不碰各搜尋範圍邊界；最大邊 32、最小邊 5、長寬比不超過 3、面積至少 20，且涵蓋至少半個候選。
- 穩定物件外加 2／4px，各用原主庫雙圖判斷。兩個待測均像螺絲、兩個參照均不像，才追加警報；任何條件不足維持原決策。
- 原保留結果與其他舊排除結果不動。模型、圖庫與原雙圖門檻不改；不得對 3129／3094 加入假答案或檔名／座標特例。

2300 穩定物件框為 16×15，三範圍一致。新兩範圍待測為 +0.114067／+0.045050，參照為 −0.140066／−0.110982。
