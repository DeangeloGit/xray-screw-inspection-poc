## 啟動

雙擊 `start.command`。服務就緒後自動開啟 http://127.0.0.1:8765。

- **使用者模式 `/`**：照片清單、原圖位置、單一放大圖與人工確認。沒有參數、分數、差分圖或版本比較。
- **工程模式 `/engineer`**：敏感度、完整候選與降序原因、正常圖、差分、九區對齊品質、候選追溯及資料夾總覽。

兩個模式可互相切換，並保留目前選取的資料夾照片。這是介面區分，沒有帳號或存取權限隔離。

如需重新建立環境：`python3 -m venv .venv`，再執行 `.venv/bin/pip install -r requirements.txt`。
終端啟動：`.venv/bin/python launch.py`。僅監聽本機，沒有向外部服務傳送照片。

## 使用者操作

1. 左側選照片，或上傳一張同型號照片。
2. 看紅框及右側放大圖，按「是螺絲／不是螺絲／不確定」。系統儲存後會前往下一個位置。
3. 全部位置判定後，照片結果依人工判定直接彙整，無需再按最後確認；沒有標記位置的照片仍需一次人工判定。
4. 儲存後可前往下一張；重新開啟同張照片會保留結果。

沒有候選也需要人工檢查整張照片，不會自動輸出 OK。有未確認或不確定的位置時，不可標記「人工未見螺絲」。修改候選判定會重新彙整照片結果。

照片資訊或局部對齊品質不足時，使用者模式會提示人工補看；詳細數據在工程模式。

## 新照片與批次

把 PNG、JPEG 或 TIFF 放進 `data/`（支援子資料夾），按左側 ↻ 重新掃描。按「全部檢查」可在背景逐張分析，結果仍待人工複核。

以完整檔案雜湊合併完全相同的照片，不會刪除原始檔。相似但不同的重拍照片不合併。正常參考由檢測機型指定；原 V1 保留 `data/ok_0.png`。參考圖不混入現場待測清單。

分析結果以影像內容、正常參考、演算法版本與門檻建立快取。同條件重開照片會重用原結果及人工判定；改變工程模式門檻會建立不同分析紀錄，原判定不會搬到不同候選上。上傳照片保存在本機工作區 data/uploads，歸屬上傳當時的來源並加入清單。

## 目前資料（2026-11-01）

23 個檔案，合併兩組完全重複檔後為 21 張不同影像，其中 1 張正常參考、20 張待測。

20 張待測已全部分析，各有 3～5 個候選；合計 23 個優先候選與 49 個其他候選。逐張候選圖的目視檢查均能看到一個明顯螺絲候選；`3.png`、`10.png`、`33.png` 各多一個固定結構優先候選。`7.png`、`9.png` 有局部對齊品質警告。

這只是候選放大圖的暫定目視檢查，不是實物確認或完整缺陷標註。數張影像疑似為同一配置的重拍，不能當作 20 個獨立缺陷案例；不據此計算精確率、召回率或量產誤報率。明細見 `review/BATCH_RESULTS.md`、`review/batch_current.json`、`review/current_samples_visual_review.csv`。

## 演算法與限制

保留原始 16-bit 檔案。分析時使用浮點正規化及最長邊 1536px 影像，嘗試四方向 ORB + RANSAC 整機對齊，再以九區 ECC 估計最多 6 個預覽像素的平移，僅在接縫平滑。套用後重新量測區域品質。

第三版以完整機體內部範圍、局部亮度補償、小範圍位移容差與輪廓相似性產生候選，再依正常鄰近結構、輪廓比例、明暗殘差、強度與面積排序。使用者模式逐一顯示目前版本全部候選。候選框映射回待測原始方向及像素座標；顯示灰階經正規化。

單一正常參考無法涵蓋所有裝配變異。範圍估計、輪廓相似性抑制與縮圖分析仍可能漏掉邊緣、重疊或較小螺絲。品質門檻是啟發式指標，不是已校準的機率。沒有候選不代表正常。

## 程式與資料

- `app.py`：本機服務、人工複核與背景批次。
- `library.py`：資料夾掃描、重複檔合併、快取與結果保存。
- `templates/user.html`、`static/user.css`、`static/user.js`：使用者介面。
- `templates/engineer.html`：工程介面。
- `detector.py`：第三版偵測；`detector_v1.py`：第一版凍結基準。
- `data/`：原始照片；`outputs/`：上傳檔、結果與人工複核紀錄，兩者不進 Git、不自動清除。
- `review/annotations.json`：最初兩處可見螺絲暫定標註。偵測器不讀取標註。
- `review/v1_candidate_review.csv`：第一版 48 個候選的目視分類。

## 檢查指令

- `.venv/bin/python batch_scan.py`：分析目前全部不同影像並保存批次明細。
- `.venv/bin/python verify_library.py`：掃描與去重、模式分離、快取、批次、人工結果保存及完成條件。
- `.venv/bin/python verify.py`：原始三張回歸、四方向原圖座標、上傳與無效輸入。
- `.venv/bin/python robustness_check.py`：同圖平移、旋轉與灰階變動檢查，不代表獨立樣本準確率。
